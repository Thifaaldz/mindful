## Saran Penamaan File

Agar gambar mudah dipanggil dari aplikasi, sebaiknya file `ChatGPT Image ...png` diubah ke **Nama File Standar** pada tabel. Dengan begitu, nama file langsung menjelaskan teknik dan step-nya, misalnya:

```text
mindful_breathing_01_preparation.png
mindful_breathing_02_notice_breath.png
body_scan_03_legs.png
sitting_meditation_04_sounds.png
informal_walking_class_03_notice_environment.png
```

Dengan format tersebut, developer tidak perlu membuka gambar satu per satu untuk mengetahui fungsi aset.
