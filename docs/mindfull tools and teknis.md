# README — 11 Teknik Mindfulness dengan Langkah Detail dan Pembagian Menit

## 1. Tujuan Dokumen

Dokumen ini menjadi panduan implementasi fitur **latihan mindfulness** pada sistem monitoring burnout guru/siswa. Setiap teknik dijelaskan dengan:

- tujuan;
- kondisi pengguna yang cocok;
- mapping status burnout;
- durasi;
- urutan latihan;
- pembagian menit per tahap;
- contoh instruksi audio;
- kondisi penghentian latihan;
- evaluasi setelah latihan.

Alur sistem:

```text
Daftar Kegiatan
      ↓
Check-in
      ↓
Melakukan Kegiatan
      ↓
Check-out
      ↓
Isi Jurnal
      ↓
Analisis Harian / Mingguan / Bulanan
      ↓
Status Burnout
🟢 Rendah / 🟡 Sedang / 🔴 Tinggi
      ↓
Analisis Keluhan / Jurnal
      ↓
Rekomendasi Teknik Mindfulness
      ↓
Pilih Durasi
      ↓
Guided Mindfulness
      ↓
Evaluasi Setelah Latihan
```

## 2. Catatan Akademik

Pendekatan utama mengacu pada **Mindfulness-Based Stress Reduction (MBSR)** yang dikembangkan oleh Jon Kabat-Zinn serta teknik yang sering digunakan dalam intervensi mindfulness berbasis MBSR/MBCT.

### Praktik yang dekat dengan MBSR

1. Mindful Breathing
2. Focused Attention
3. Body Scan Meditation
4. Sitting Meditation
5. Mindful Movement / Hatha Yoga
6. Walking Meditation
7. Informal Mindfulness

### Praktik tambahan/adaptasi mindfulness

8. Open Monitoring / Choiceless Awareness
9. Mindfulness of Sounds
10. Loving-Kindness Meditation
11. Mountain Meditation

> Penulisan yang aman untuk skripsi: **“Sistem mengadaptasi teknik mindfulness yang digunakan dalam MBSR dan intervensi mindfulness berbasis MBSR/MBCT.”**

## 3. Prinsip Durasi

| Mode | Durasi | Penggunaan |
|---|---:|---|
| Quick | 3–5 menit | Jeda singkat, burnout rendah |
| Standard | 5–10 menit | Burnout rendah–sedang |
| Recovery | 10–15 menit | Burnout sedang |
| Deep Recovery | 15–20 menit | Burnout tinggi / sesi lebih mendalam |

Rekomendasi umum:

```text
🟢 Rendah  → 3–5 menit
🟡 Sedang  → 5–15 menit
🔴 Tinggi  → 10–20 menit + rekomendasi pemulihan
```

Durasi bukan ukuran diagnosis. Pengguna tetap boleh memilih sesi yang lebih singkat jika tidak nyaman.

# 4. Teknik 1 — Mindful Breathing

## Deskripsi

Mindful Breathing menggunakan **napas sebagai anchor perhatian**. Pengguna tidak diminta memaksakan napas menjadi panjang atau dalam; fokus utama adalah menyadari napas sebagaimana adanya.

## Tujuan

- mengembalikan fokus ke saat ini;
- memberikan jeda setelah aktivitas;
- melatih konsentrasi;
- membantu pengguna menyadari distraksi;
- cocok sebagai latihan awal sebelum teknik lain.

## Cocok Ketika

- sulit fokus;
- stres ringan;
- pikiran mulai ramai;
- sebelum mengajar/rapat;
- setelah checkout kegiatan;
- butuh jeda singkat.

## Mapping Burnout

```text
🟢 Rendah  → Sangat cocok
🟡 Sedang  → Cocok
🔴 Tinggi  → Bisa sebagai latihan awal, bukan satu-satunya respons
```

## Durasi

- 3 menit — quick reset
- 5 menit — standard
- 10 menit — recovery

## Mindful Breathing 3 Menit

### 00:00–00:30 — Persiapan

```text
Duduk atau berdiri dengan nyaman.
Lepaskan ketegangan yang tidak perlu.
Tidak perlu mengubah napas.
```

### 00:30–01:30 — Sadari Napas

```text
Perhatikan napas masuk.
Perhatikan napas keluar.
Sadari sensasi pada hidung, dada, atau perut.
```

### 01:30–02:30 — Menangani Distraksi

```text
Jika pikiran berpindah, sadari saja.
Tidak perlu merasa gagal.
Kembali perlahan pada napas.
```

### 02:30–03:00 — Penutup

```text
Sadari tubuh dan lingkungan.
Ambil satu napas alami.
Buka mata perlahan jika sebelumnya tertutup.
```

## Mindful Breathing 5 Menit

```text
00:00–01:00 → Persiapan tubuh
01:00–02:30 → Fokus napas
02:30–04:00 → Sadari distraksi dan kembali ke napas
04:00–04:30 → Sadari tubuh
04:30–05:00 → Penutup
```

## Mindful Breathing 10 Menit

```text
00:00–01:00 → Persiapan
01:00–04:00 → Perhatian pada napas
04:00–07:00 → Latihan kembali dari distraksi
07:00–09:00 → Napas + sensasi tubuh
09:00–10:00 → Penutup
```

## Contoh Audio

```text
Perhatikan napas Anda tanpa mengubahnya.
Saat napas masuk, sadari napas masuk.
Saat napas keluar, sadari napas keluar.
Jika perhatian berpindah, cukup sadari dan kembali pada napas.
```

# 5. Teknik 2 — Focused Attention Meditation

## Deskripsi

Focused Attention melatih pengguna mempertahankan perhatian pada **satu objek tertentu** seperti napas, telapak kaki, telapak tangan, atau suara stabil.

## Tujuan

- meningkatkan konsentrasi;
- membantu mengurangi distraksi;
- melatih kemampuan kembali ke satu fokus;
- membangun dasar sebelum Open Monitoring.

## Cocok Ketika

- mudah terdistraksi;
- sulit berkonsentrasi;
- perhatian sering berpindah;
- sering mengecek ponsel saat bekerja/belajar.

## Mapping Burnout

```text
🟢 Rendah  → Cocok
🟡 Sedang  → Sangat cocok bila masalah utama adalah fokus
🔴 Tinggi  → Pendamping, bukan respons utama
```

## Durasi

5–10 menit.

## Focused Attention 5 Menit

### 00:00–01:00 — Pilih Anchor

Pilih satu objek, misalnya sensasi napas di ujung hidung.

### 01:00–03:30 — Pertahankan Fokus

Perhatikan anchor yang dipilih tanpa mengejar pikiran lain.

### 03:30–04:30 — Kembali dari Distraksi

Jika perhatian berpindah:

```text
Sadari → beri label sederhana “berpikir” → kembali ke anchor.
```

### 04:30–05:00 — Penutup

Sadari seluruh tubuh dan lingkungan.

## Focused Attention 10 Menit

```text
00:00–01:00 → Persiapan
01:00–03:00 → Memilih anchor
03:00–07:00 → Mempertahankan fokus
07:00–09:00 → Latihan kembali dari distraksi
09:00–10:00 → Penutup
```

# 6. Teknik 3 — Body Scan Meditation

## Deskripsi

Body Scan mengarahkan perhatian secara sistematis dari satu bagian tubuh ke bagian lainnya tanpa memaksa sensasi berubah.

## Tujuan

- meningkatkan body awareness;
- mengenali ketegangan;
- membantu pengguna menyadari kelelahan fisik;
- memberi ruang pemulihan setelah aktivitas panjang.

## Cocok Ketika

- badan sangat lelah;
- bahu tegang;
- leher kaku;
- punggung pegal;
- terlalu lama berdiri/duduk;
- kelelahan setelah mengajar.

## Mapping Burnout

```text
🟢 Rendah  → Opsional
🟡 Sedang  → Sangat cocok
🔴 Tinggi  → Sangat cocok sebagai pendamping recovery
```

## Durasi

- Quick: 5 menit
- Standard: 10 menit
- Recovery: 15 menit
- Deep: 20 menit

## Body Scan 10 Menit

### 00:00–01:00 — Persiapan

Duduk atau berbaring nyaman. Sadari beberapa napas.

### 01:00–02:00 — Kaki

Sadari telapak kaki, jari, suhu, berat/ringan.

### 02:00–03:00 — Tungkai

Sadari betis, lutut, paha.

### 03:00–04:00 — Pinggang/Panggul

Sadari tekanan tubuh pada kursi/lantai.

### 04:00–05:00 — Perut

Sadari gerakan perut saat bernapas.

### 05:00–06:00 — Dada

Sadari naik-turunnya dada.

### 06:00–07:00 — Tangan

```text
Jari → telapak → pergelangan → lengan.
```

### 07:00–08:00 — Bahu dan Leher

Sadari ketegangan tanpa memaksa hilang.

### 08:00–09:00 — Wajah dan Kepala

```text
Rahang → pipi → mata → dahi → kepala.
```

### 09:00–10:00 — Seluruh Tubuh

Sadari tubuh sebagai satu kesatuan dan kembali ke napas.

## Body Scan 15 Menit

```text
00:00–01:30 → Persiapan
01:30–03:00 → Kaki
03:00–04:30 → Tungkai
04:30–06:00 → Pinggang/panggul
06:00–07:30 → Perut
07:30–09:00 → Dada
09:00–10:30 → Tangan
10:30–12:00 → Bahu/leher
12:00–13:30 → Wajah/kepala
13:30–15:00 → Seluruh tubuh
```

## Body Scan 20 Menit

Gunakan sekitar **1,5–2 menit per area tubuh** dan tambahkan jeda hening 10–20 detik antar bagian.

# 7. Teknik 4 — Sitting Meditation

## Deskripsi

Sitting Meditation adalah meditasi duduk yang memperluas perhatian dari napas menuju sensasi tubuh, suara, pikiran, dan emosi.

## Tujuan

- menyadari pikiran tanpa langsung bereaksi;
- mengenali emosi;
- membantu mengelola beban mental;
- melatih awareness yang lebih luas.

## Cocok Ketika

- banyak pikiran;
- overthinking;
- sulit tenang;
- terus memikirkan pekerjaan;
- merasa kewalahan.

## Mapping Burnout

```text
🟢 Rendah  → Opsional
🟡 Sedang  → Cocok
🔴 Tinggi  → Cocok sebagai pendamping recovery
```

## Durasi

5–15 menit.

## Sitting Meditation 10 Menit

```text
00:00–01:00 → Posisi tubuh
01:00–03:00 → Napas
03:00–05:00 → Sensasi tubuh
05:00–06:30 → Suara
06:30–08:00 → Pikiran
08:00–09:00 → Emosi
09:00–10:00 → Penutup
```

### Detail

**00:00–01:00:** duduk nyaman, punggung tegak tetapi tidak kaku.

**01:00–03:00:** fokus pada napas.

**03:00–05:00:** sadari tekanan kursi, kaki, tangan, bahu.

**05:00–06:30:** dengarkan suara tanpa menilai.

**06:30–08:00:** sadari pikiran yang muncul tanpa mengikuti ceritanya.

**08:00–09:00:** sadari emosi yang hadir.

**09:00–10:00:** kembali ke napas dan lingkungan.

## Sitting Meditation 15 Menit

```text
00:00–02:00 → Persiapan
02:00–05:00 → Napas
05:00–08:00 → Sensasi tubuh
08:00–10:00 → Suara
10:00–12:00 → Pikiran
12:00–14:00 → Emosi
14:00–15:00 → Penutup
```

# 8. Teknik 5 — Mindful Movement / Hatha Yoga

## Deskripsi

Gerakan/peregangan ringan dengan perhatian pada tubuh, napas, dan batas kemampuan tubuh. Tujuan utamanya bukan fleksibilitas atau olahraga berat.

## Tujuan

- membantu tubuh bergerak setelah duduk/berdiri lama;
- meningkatkan body awareness;
- recovery aktif;
- membantu mengenali ketegangan.

## Cocok Ketika

- punggung pegal;
- bahu tegang;
- leher kaku;
- terlalu lama duduk;
- terlalu lama berdiri.

## Mapping Burnout

```text
🟡 Sedang  → Sangat cocok
🔴 Tinggi  → Cocok bila keluhan fisik dominan
```

## Durasi

5–15 menit.

## Mindful Movement 5 Menit

```text
00:00–01:00 → Grounding dan napas
01:00–02:00 → Bahu
02:00–03:00 → Tangan
03:00–04:00 → Leher
04:00–05:00 → Penutup
```

### Gerakan

- naik-turunkan bahu perlahan;
- angkat tangan tanpa memaksa;
- putar bahu jika nyaman;
- gerakkan leher perlahan ke kanan/kiri;
- berhenti jika terasa nyeri tajam.

## Mindful Movement 10 Menit

```text
00:00–01:00 → Grounding
01:00–03:00 → Bahu dan tangan
03:00–05:00 → Leher dan punggung atas
05:00–07:00 → Pinggang
07:00–09:00 → Kaki
09:00–10:00 → Penutup
```

## Safety

Hentikan jika muncul:

- nyeri tajam;
- pusing;
- sesak;
- rasa tidak aman saat bergerak.

# 9. Teknik 6 — Walking Meditation

## Deskripsi

Berjalan dengan kecepatan nyaman sambil menyadari langkah, kontak kaki dengan lantai, gerakan tubuh, dan napas.

## Tujuan

- memberikan jeda aktif;
- grounding;
- cocok setelah duduk lama;
- melatih awareness saat bergerak.

## Cocok Ketika

- jenuh;
- terlalu lama duduk;
- baru selesai mengajar;
- butuh bergerak;
- ada jeda antar kegiatan.

## Mapping Burnout

```text
🟢 Rendah  → Sangat cocok
🟡 Sedang  → Cocok
🔴 Tinggi  → Tidak menjadi prioritas bila sangat lelah
```

## Durasi

5–10 menit.

## Walking Meditation 5 Menit

```text
00:00–01:00 → Berdiri dan sadari kontak kaki
01:00–02:00 → Mulai berjalan
02:00–03:00 → Fokus langkah: angkat–bergerak–menyentuh
03:00–04:00 → Sadari gerakan seluruh tubuh
04:00–05:00 → Perlambat, berhenti, sadari napas
```

## Walking Meditation 10 Menit

```text
00:00–01:00 → Berdiri
01:00–03:00 → Sensasi langkah
03:00–06:00 → Gerakan tubuh
06:00–08:00 → Napas + langkah
08:00–09:00 → Lingkungan
09:00–10:00 → Penutup
```

## Safety

Jangan dilakukan sambil:

- menyeberang jalan;
- mengemudi;
- berada di area yang membutuhkan kewaspadaan penuh.

# 10. Teknik 7 — Open Monitoring / Choiceless Awareness

## Deskripsi

Pengguna tidak mempertahankan satu objek tertentu. Pengalaman apa pun yang muncul—pikiran, suara, emosi, sensasi—diamati tanpa langsung bereaksi.

## Tujuan

- melatih non-reactivity;
- membantu menghadapi pikiran ramai;
- mengenali pengalaman yang muncul dan berubah;
- cocok untuk emosi bercampur.

## Cocok Ketika

- overwhelmed;
- pikiran sangat ramai;
- banyak hal muncul sekaligus;
- emosi bercampur.

## Mapping Burnout

```text
🟡 Sedang  → Cocok
🔴 Tinggi  → Cocok sebagai pendamping
```

## Durasi

10–15 menit.

## Open Monitoring 10 Menit

```text
00:00–02:00 → Stabilkan diri melalui napas
02:00–04:00 → Buka awareness ke tubuh
04:00–06:00 → Sadari suara
06:00–08:00 → Sadari pikiran dan emosi
08:00–09:00 → Awareness menyeluruh
09:00–10:00 → Kembali ke napas dan tutup sesi
```

## Prinsip

```text
Tidak mengejar pengalaman.
Tidak menolak pengalaman.
Tidak memilih pengalaman.
Cukup menyadari.
```

# 11. Teknik 8 — Mindfulness of Sounds

## Deskripsi

Menggunakan pengalaman mendengar sebagai anchor perhatian tanpa memberi penilaian pada suara.

## Tujuan

- grounding;
- alternatif untuk pengguna yang kurang nyaman fokus pada napas;
- membantu mengembalikan awareness.

## Cocok Ketika

- sulit fokus;
- butuh grounding;
- pikiran bergerak terus;
- ingin latihan ringan.

## Mapping Burnout

```text
🟢 Rendah  → Cocok
🟡 Sedang  → Cocok
🔴 Tinggi  → Bukan rekomendasi utama
```

## Durasi

5–10 menit.

## Mindfulness of Sounds 5 Menit

```text
00:00–01:00 → Persiapan
01:00–02:00 → Dengarkan suara dekat
02:00–03:00 → Dengarkan suara jauh
03:00–04:00 → Sadari suara muncul–berubah–menghilang
04:00–05:00 → Kembali pada napas dan tutup sesi
```

## Aturan

Hindari label:

```text
“bagus”
“jelek”
“mengganggu”
```

Gunakan sikap:

```text
“ada suara”
```

# 12. Teknik 9 — Loving-Kindness Meditation

## Deskripsi

Latihan untuk mengembangkan sikap baik, penerimaan, dan compassion terhadap diri sendiri dan orang lain.

## Tujuan

- membantu self-criticism;
- menghadapi frustrasi;
- mendukung regulasi emosi;
- menumbuhkan compassion.

## Cocok Ketika

- merasa gagal;
- menyalahkan diri;
- frustrasi;
- konflik;
- tekanan emosional.

## Mapping Burnout

```text
🟡 Sedang  → Cocok bila emosi negatif dominan
🔴 Tinggi  → Relevan sebagai pendamping
```

## Durasi

5–15 menit.

## Loving-Kindness 10 Menit

### 00:00–02:00 — Stabilkan Diri

Fokus pada napas dan posisi tubuh.

### 02:00–05:00 — Kepada Diri Sendiri

Contoh kalimat:

```text
Semoga saya dapat melalui kondisi ini dengan tenang.
Semoga saya dapat memperlakukan diri dengan baik.
Semoga saya mendapatkan ruang untuk beristirahat.
```

### 05:00–07:00 — Kepada Orang yang Dipercaya

```text
Semoga Anda sehat.
Semoga Anda tenang.
Semoga Anda mendapatkan kebaikan.
```

### 07:00–09:00 — Perluas

Jika nyaman, perluas ke orang lain.

### 09:00–10:00 — Penutup

Kembali ke napas dan tubuh.

# 13. Teknik 10 — Mountain Meditation

## Deskripsi

Meditasi visualisasi yang menggunakan gunung sebagai metafora kestabilan saat lingkungan berubah.

## Tujuan

- melatih kestabilan emosional;
- membantu menghadapi perubahan;
- mengembangkan acceptance;
- memberi perspektif bahwa pikiran dan emosi berubah.

## Cocok Ketika

- emosi naik-turun;
- merasa tidak stabil;
- banyak perubahan;
- tekanan tinggi;
- sulit menerima keadaan.

## Mapping Burnout

```text
🟡 Sedang  → Cocok
🔴 Tinggi  → Cocok sebagai pendamping
```

## Durasi

10–20 menit.

## Mountain Meditation 15 Menit

```text
00:00–02:00 → Persiapan dan napas
02:00–05:00 → Bayangkan bentuk gunung
05:00–08:00 → Bayangkan perubahan cuaca di sekitarnya
08:00–11:00 → Hubungkan dengan perubahan pikiran/emosi
11:00–13:00 → Rasakan kestabilan tubuh
13:00–15:00 → Kembali pada napas dan tutup sesi
```

### Detail Visualisasi

Bayangkan:

```text
awan datang
hujan turun
angin bertiup
matahari muncul
```

Gunung tetap berdiri. Hubungkan secara metaforis dengan pengalaman bahwa situasi, emosi, dan pikiran dapat berubah.

# 14. Teknik 11 — Informal Mindfulness

## Deskripsi

Mindfulness dilakukan saat aktivitas sehari-hari, sehingga pengguna tidak perlu membuka sesi meditasi formal.

## Tujuan

- membangun kebiasaan;
- prevention;
- maintenance;
- cocok untuk pengguna dengan waktu terbatas.

## Mapping Burnout

```text
🟢 Rendah  → Sangat cocok
🟡 Sedang  → Tambahan
🔴 Tinggi  → Tidak cukup sebagai satu-satunya rekomendasi
```

## A. Mindful Drinking — 2 Menit

```text
00:00–00:30 → Pegang gelas dan sadari suhu
00:30–01:00 → Perhatikan warna/aroma
01:00–01:30 → Minum perlahan
01:30–02:00 → Sadari sensasi setelah menelan
```

## B. Mindful Eating — 5 Menit

```text
00:00–01:00 → Perhatikan warna, bentuk, aroma
01:00–02:00 → Ambil satu suapan secara sadar
02:00–03:30 → Kunyah perlahan
03:30–04:30 → Sadari rasa dan tekstur
04:30–05:00 → Sadari kondisi tubuh
```

## C. Mindful Walking to Class — 3 Menit

```text
00:00–01:00 → Sadari langkah
01:00–02:00 → Sadari napas
02:00–03:00 → Sadari lingkungan
```

Selama latihan, hindari membuka ponsel jika situasi memungkinkan.

# 15. Mapping Berdasarkan Burnout

Fokus:

```text
PREVENTION + MAINTENANCE + FOCUS
```

| Kondisi | Teknik | Durasi |
|---|---|---:|
| Kondisi normal | Informal Mindfulness | 2–5 menit |
| Sulit fokus ringan | Mindful Breathing | 3–5 menit |
| Mudah terdistraksi | Focused Attention | 5 menit |
| Butuh grounding | Mindfulness of Sounds | 5 menit |
| Duduk lama | Walking Meditation | 5–10 menit |

# 16. 🟡 Burnout Sedang

Fokus:

```text
RECOVERY + BODY AWARENESS + MENTAL/EMOTIONAL AWARENESS
```

| Kondisi | Teknik | Durasi |
|---|---|---:|
| Lelah fisik | Body Scan | 10–15 menit |
| Pegal/kaku | Mindful Movement | 5–10 menit |
| Sulit fokus | Mindful Breathing / Focused Attention | 5–10 menit |
| Banyak pikiran | Sitting Meditation | 10 menit |
| Overwhelmed | Open Monitoring | 10–15 menit |
| Jenuh | Walking Meditation | 5–10 menit |
| Frustrasi | Loving-Kindness | 10 menit |
| Emosi tidak stabil | Mountain Meditation | 10–15 menit |

---

# 17. 🔴 Burnout Tinggi

Fokus:

```text
RECOVERY PRIORITY + REDUCE OVERLOAD + MINDFULNESS AS SUPPORT
```

| Kondisi | Teknik | Durasi |
|---|---|---:|
| Sangat lelah | Body Scan | 15–20 menit |
| Tubuh sangat tegang | Mindful Movement | 10–15 menit |
| Overthinking | Sitting Meditation | 10–15 menit |
| Overwhelmed | Open Monitoring | 10–15 menit |
| Frustrasi/self-criticism | Loving-Kindness | 10–15 menit |
| Emosi tidak stabil | Mountain Meditation | 15–20 menit |

Tambahkan rekomendasi non-meditasi:

- ambil waktu jeda;
- kurangi aktivitas tidak mendesak jika memungkinkan;
- pastikan waktu istirahat;
- komunikasikan beban kerja;
- cari bantuan profesional jika kondisi berat atau menetap.

# 18. Contoh Rule-Based Recommendation Engine

```pseudo
IF burnout_status == "LOW":
    IF sulit_fokus:
        recommend("Mindful Breathing", 5)
    ELSE IF terdistraksi:
        recommend("Focused Attention", 5)
    ELSE IF duduk_lama OR jenuh:
        recommend("Walking Meditation", 5)
    ELSE:
        recommend("Informal Mindfulness", 3)
```

```pseudo
IF burnout_status == "MEDIUM":
    IF lelah_fisik OR tubuh_tegang:
        recommend("Body Scan", 10)
    ELSE IF kaku OR duduk_lama:
        recommend("Mindful Movement", 10)
    ELSE IF banyak_pikiran:
        recommend("Sitting Meditation", 10)
    ELSE IF overwhelmed:
        recommend("Open Monitoring", 10)
    ELSE IF frustrasi OR self_criticism:
        recommend("Loving-Kindness", 10)
    ELSE IF emosi_tidak_stabil:
        recommend("Mountain Meditation", 10)
    ELSE:
        recommend("Mindful Breathing", 5)
```

```pseudo
IF burnout_status == "HIGH":
    show_recovery_warning()

    IF sangat_lelah OR tubuh_tegang:
        primary = "Body Scan"
    ELSE IF overthinking:
        primary = "Sitting Meditation"
    ELSE IF overwhelmed:
        primary = "Open Monitoring"
    ELSE IF frustrasi OR self_criticism:
        primary = "Loving-Kindness"
    ELSE IF emosi_tidak_stabil:
        primary = "Mountain Meditation"
    ELSE:
        primary = "Body Scan"

    show(primary)
    show_rest_recommendation()
```

# 20. Reminder Keselamatan

Hentikan latihan bila muncul:

- pusing berat;
- nyeri tajam;
- sesak;
- panik yang meningkat;
- rasa tidak aman;
- ketidaknyamanan fisik signifikan.

Untuk Mindful Movement, jangan memaksakan peregangan.

Untuk Walking Meditation, jangan dilakukan sambil menyeberang jalan, mengemudi, atau di area yang membutuhkan kewaspadaan penuh.
