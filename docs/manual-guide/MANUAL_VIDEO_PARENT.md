# Manual Video Parent MindfulEdu

Dokumen ini adalah panduan video khusus role Parent atau Orang Tua.

---

## 1. Tujuan Role

Parent memakai MindfulEdu untuk memantau anak yang sudah terhubung. Parent dapat melihat activity anak, mood check-in, mood check-out, hasil analisis burnout, dan rekomendasi pendampingan.

Parent tidak mengubah data anak. Role ini bersifat monitoring.

---

## 2. Alur Video Singkat

```text
Pilih role Orang Tua
  -> register atau login
  -> masukkan kode verifikasi siswa
  -> pilih/isi sekolah anak
  -> hubungkan anak
  -> buka dashboard anak
  -> lihat activity anak
  -> lihat mood dan analisis anak
  -> lihat rekomendasi pendampingan
```

---

## 3. Register Parent

Yang ditampilkan:

- pilih role Orang Tua;
- register dengan email atau Google;
- login.

Naskah:

```text
Parent dapat membuat akun dari aplikasi mobile. Setelah login, parent perlu menghubungkan anak menggunakan kode verifikasi siswa.
```

Catatan:

- parent tidak perlu approval admin seperti guru/siswa;
- parent baru bisa melihat data anak setelah berhasil menghubungkan anak.

---

## 4. Menghubungkan Anak

Data yang dibutuhkan:

| Field | Keterangan |
|---|---|
| Kode verifikasi siswa | Diambil dari profil siswa |
| Sekolah anak | Harus sama dengan sekolah siswa |

Alur:

```text
Parent login
  -> buka menu Anak atau Profil
  -> pilih Hubungkan Anak
  -> masukkan kode siswa
  -> masukkan/pilih sekolah
  -> submit
  -> anak muncul di daftar monitoring
```

Naskah:

```text
Untuk menjaga keamanan data, parent harus memasukkan kode verifikasi siswa dan sekolah yang sesuai. Jika kode atau sekolah tidak cocok, sistem akan menolak proses hubungkan anak.
```

Checklist:

```text
[ ] Kode siswa tersedia dari profil siswa
[ ] Parent memasukkan kode siswa
[ ] Parent memasukkan sekolah yang benar
[ ] Anak berhasil terhubung
[ ] Anak tampil pada dashboard parent
```

---

## 5. Dashboard Parent

Dashboard parent menampilkan:

| Data | Fungsi |
|---|---|
| Daftar anak | Anak yang sudah terhubung |
| Filter tanggal | Memilih tanggal activity anak |
| Activity anak | Kegiatan anak pada tanggal tertentu |
| Mood check-in | Kondisi awal anak |
| Mood check-out | Kondisi akhir anak |
| Guru terkait | Guru jika activity berasal dari kelas |
| Analisis burnout | Ringkasan kondisi anak |
| Rekomendasi | Saran pendampingan atau latihan |

Alur rekaman:

```text
Buka dashboard parent
  -> pilih anak
  -> pilih tanggal
  -> lihat activity anak
  -> buka detail mood
  -> lihat analisis
  -> baca rekomendasi pendampingan
```

Naskah:

```text
Setelah anak terhubung, parent dapat melihat activity anak berdasarkan tanggal. Parent juga bisa melihat mood sebelum dan setelah activity, hasil analisis anak, serta rekomendasi pendampingan yang dapat dilakukan di rumah.
```

---

## 6. Batasan Parent

Parent tidak dapat:

- membuat activity untuk anak;
- mengedit activity anak;
- mengisi jurnal anak;
- melihat siswa lain;
- approve akun guru/siswa;
- membuka dashboard admin sekolah;
- mengubah hasil analisis.

Naskah:

```text
Akses parent dibatasi agar privasi siswa tetap terjaga. Parent hanya melihat data anak yang sudah terhubung melalui kode verifikasi.
```

---

## 7. Contoh Narasi Monitoring Anak

```text
Pada halaman ini, parent dapat memilih tanggal tertentu untuk melihat aktivitas anak. Jika anak sudah melakukan check-in dan check-out, mood awal dan mood akhir akan tampil. Sistem juga menampilkan ringkasan analisis dan rekomendasi pendampingan yang dapat membantu parent memahami kondisi anak setelah kegiatan belajar.
```
