# Manual Guide Video MindfulEdu

Folder ini berisi panduan video manual MindfulEdu yang dipisah per topik dan per role.

Urutan baca yang disarankan:

| No | File | Isi |
|---:|---|---|
| 1 | `README_PERKENALAN_APLIKASI.md` | Perkenalan aplikasi, tujuan sistem, fitur utama, dan alur besar |
| 2 | `MANUAL_VIDEO_SUPER_ADMIN.md` | Panduan video role super admin |
| 3 | `MANUAL_VIDEO_ADMIN_SEKOLAH.md` | Panduan video role admin sekolah |
| 4 | `MANUAL_VIDEO_GURU.md` | Panduan video role guru |
| 5 | `MANUAL_VIDEO_SISWA.md` | Panduan video role siswa |
| 6 | `MANUAL_VIDEO_PARENT.md` | Panduan video role parent/orang tua |
| 7 | `MANUAL_VIDEO_TOOLKIT_ANALISIS.md` | Panduan video fitur analisis dan toolkit mindfulness |

Target video lengkap:

```text
Perkenalan aplikasi
  -> pendaftaran sekolah
  -> super admin approve sekolah
  -> super admin buat admin sekolah
  -> admin sekolah buat kelas
  -> guru register dan approved
  -> siswa register dan approved
  -> guru membuat activity kelas
  -> siswa join activity kelas
  -> check-in/check-out dan jurnal
  -> analisis burnout
  -> rekomendasi mindfulness
  -> parent monitoring
```

Catatan:

- gunakan akun demo saat rekaman;
- jangan tampilkan password asli, API key, `.env`, atau file `.pem`;
- jelaskan bahwa analisis burnout adalah alat bantu refleksi, bukan diagnosis medis.
