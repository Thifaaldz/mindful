# Manual Video Super Admin MindfulEdu

Dokumen ini adalah panduan video khusus role Super Admin.

---

## 1. Tujuan Role

Super Admin adalah pengelola pusat MindfulEdu. Role ini memiliki akses paling luas untuk memantau dan mengatur seluruh sekolah, admin sekolah, guru, siswa, parent, activity, analisis, observasi, dan data mindfulness.

Super Admin digunakan untuk:

- menyetujui atau menolak pendaftaran sekolah;
- membuat akun admin sekolah;
- memantau semua data lintas sekolah;
- memastikan struktur data sekolah, kelas, user, dan activity berjalan benar.

---

## 2. Akses

```text
URL Admin Panel : https://mindfulapps.pkmueu.online/admin
Role            : super_admin
Contoh akun     : admin@admin.com
```

Catatan video:

- jangan tampilkan password asli;
- gunakan akun demo jika video akan dipublikasikan.

---

## 4. Langkah Detail Rekaman

### 4.1 Login

Yang ditampilkan:

- halaman login admin;
- email super admin;
- dashboard setelah login.

Naskah:

```text
Pertama, super admin masuk melalui halaman admin panel. Role ini memiliki akses pusat untuk mengelola semua sekolah dan memantau keseluruhan data sistem.
```

### 4.2 Review Pendaftaran Sekolah

Yang ditampilkan:

- menu School Registrations;
- daftar sekolah pending;
- detail data sekolah;
- action approve/reject.

Naskah:

```text
Saat sekolah mendaftar dari website, datanya masuk ke menu School Registrations dengan status pending. Super admin mengecek kelengkapan data sekolah, wilayah, dan kontak penanggung jawab. Jika valid, sekolah dapat disetujui.
```

Checklist:

```text
[ ] School Registrations tampil
[ ] Data sekolah pending bisa dibuka
[ ] Detail sekolah terlihat
[ ] Action approve/reject tersedia
```

### 4.3 Mengelola Sekolah

Yang ditampilkan:

- menu Schools;
- sekolah approved;
- detail sekolah;
- data provinsi, kota/kabupaten, kecamatan.

Naskah:

```text
Setelah disetujui, sekolah berpindah menjadi sekolah aktif. Sekolah ini akan muncul di pilihan sekolah pada aplikasi mobile saat guru dan siswa melakukan registrasi.
```

### 4.4 Membuat Admin Sekolah

Yang ditampilkan:

- menu School Admins;
- form create admin sekolah;
- pilih sekolah;
- isi nama dan email admin;
- simpan.

Naskah:

```text
Super admin dapat membuat admin sekolah. Admin sekolah ini nantinya hanya mengelola data sekolah yang dipilih, sehingga data antar sekolah tetap terpisah.
```

Checklist:

```text
[ ] Form admin sekolah tampil
[ ] Sekolah bisa dipilih
[ ] Admin sekolah berhasil dibuat
[ ] Role admin sekolah tersimpan
```

### 4.5 Monitoring Data User

Menu yang ditampilkan:

| Menu | Fungsi |
|---|---|
| Teacher Registrations | Melihat guru pending semua sekolah |
| Student Registrations | Melihat siswa pending semua sekolah |
| Teacher Data | Melihat guru approved |
| Student Data | Melihat siswa approved |
| Parent Management | Melihat data parent |
| Login Histories | Melihat riwayat login |

Naskah:

```text
Super admin dapat melihat seluruh data pengguna. Data ini berguna untuk memastikan proses registrasi, approval, dan login berjalan normal di semua sekolah.
```

### 4.6 Monitoring Activity dan Analisis

Menu yang ditampilkan:

| Menu | Fungsi |
|---|---|
| Teacher Activities | Activity guru |
| Student Activities | Activity siswa |
| Teacher Burnout Analysis | Analisis guru |
| Student Burnout Analysis | Analisis siswa |
| Student Observations | Observasi siswa dari activity kelas |

Naskah:

```text
Super admin dapat melihat activity dan hasil analisis secara menyeluruh. Data ini membantu monitoring sistem dan memastikan fitur activity, jurnal, serta analisis berjalan.
```

### 4.7 Mengelola Mindfulness

Menu yang ditampilkan:

| Menu | Fungsi |
|---|---|
| Mindful Tactics | Mengelola teknik mindfulness |
| Mindfulness Sessions | Melihat sesi latihan pengguna |
| Badges | Mengelola badge |

Naskah:

```text
Teknik mindfulness yang muncul di aplikasi berasal dari katalog Mindful Tactics. Super admin dapat memantau teknik, sesi latihan, dan badge pengguna.
```

---

## 5. Fungsi Penting Yang Harus Disebut

- Super admin melihat semua sekolah.
- Super admin approve sekolah.
- Super admin membuat admin sekolah.
- Super admin dapat melihat guru, siswa, parent, activity, analisis, dan observasi.
- Super admin menjaga data master sistem.
- Approval guru/siswa tetap bisa dipantau oleh super admin.
